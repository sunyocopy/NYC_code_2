LINE Messaging API Setup Guide

คำแนะนำขั้นตอนการตั้งค่าบอทและตัวแปรสภาพแวดล้อม (.env)

1

LINE Developers Console

เข้าสู่ LINE Developers → สร้าง Provider → สร้าง Messaging API channel

2

Channel Access Token

ไปที่แท็บ Messaging API → เลื่อนลงไปที่ Channel access token → คลิก Issue (Long-lived token)

3

Target Group / User ID

เชิญบอทเข้า Group LINE → รับ groupId จาก Webhook event หรือใช้ userId ของผู้ใช้งาน

ตัวอย่างการตั้งค่าไฟล์ .env

LINE_CHANNEL_ACCESS_TOKEN=eyJhbGciOiJIUzI1NiJ9.xxxxxxxxxxxxxx...
LINE_TARGET_GROUP_ID=C0123456789abcdef0123456789abcdef
PORT=3000
